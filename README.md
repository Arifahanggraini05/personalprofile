# Personal Website & Portfolio Page

Repositori ini berisi proyek situs web personal (Portofolio) yang dibangun menggunakan HTML5 dan CSS3. Proyek ini diselesaikan sebagai **Tugas Akhir Submission** untuk kelulusan kelas belajar web development di platform Dicoding.

---

## Deskripsi Proyek

Situs web ini menyajikan halaman portofolio interaktif dan responsif milik **Arifah Anggraini Nukuhehe**. Web ini menampilkan informasi pribadi, latar belakang pendidikan, serta daftar proyek web yang telah dikerjakan.

### Fitur Utama:
- **Header & Navigation Sticky:** Navigasi yang tetap berada di atas saat pengguna menggeser (*scroll*) halaman.
- **Biografi & Aspirasi Karir:** Informasi singkat mengenai latar belakang pendidikan dan cita-cita sebagai *Fullstack Developer*.
- **Galeri Portofolio:** Menampilkan proyek-proyek yang pernah dibuat sebelumnya lengkap dengan tautan demonstrasi.
- **Sidebar Profil:** Informasi kontak lengkap termasuk tautan ke LinkedIn dan GitHub dalam format tabel yang rapi.
- **Desain Responsif (Responsive Design):** Menggunakan *CSS Media Queries* sehingga tampilan menyesuaikan ukuran layar perangkat (Desktop, Tablet, & Mobile).

---

## Teknologi yang Digunakan

- **HTML5:** Struktur utama halaman web (penggunaan elemen semantik seperti `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, dan `<footer>`).
- **CSS3:** Penataan gaya tampilan, tata letak menggunakan Flexbox dan Grid, media query responsif, serta efek *hover*.
- **Google Fonts:** Menggunakan font *Quicksand* untuk tipografi yang bersih dan modern.

## Cara Menjalankan Proyek di Lokal

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/arifahanggraini05/personalprofile.git
   ```
2. **Masuk ke direktori proyek:**
   ```bash
   cd personalprofile
   ```
3. **Buka file `index.html`:**
   Buka file `index.html` langsung dengan melakukan klik dua kali pada file tersebut atau jalankan menggunakan ekstensi *Live Server* di VS Code.
